# Working on this repo

- Commit and push directly to `main` unless the user says otherwise. The site deploys from `main`.
- Before pushing, run `npm test` and `npm run build` (CI runs both).
- No personal data anywhere in code, comments, tests, docs or commit messages: no real names, employers,
  salaries, dates or figures from anyone's documents. Examples use made-up companies and figures
  (Acme, Northwind, Zeta, Sigma; round, illustrative amounts).
- Don't mention the assistant or add assistant attribution in code, comments, docs or commit messages.
